# Security

trimproof is pre-alpha. It forwards provider API keys and may handle sensitive request data, so please report vulnerabilities privately rather than in a public issue.

Report a vulnerability through GitHub's private vulnerability reporting: the **Security** tab of this repository, then **Report a vulnerability**.

Useful reports include the version or commit, the configuration involved (policy file and flags, with secrets removed) and the steps to reproduce.

Only the latest release is supported with fixes.
